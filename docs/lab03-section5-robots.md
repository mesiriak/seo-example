# Розділ 5. Файл robots.txt

## 5.1. Стан до оптимізації

| Параметр | Значення |
|----------|----------|
| URL `…/robots.txt` | **404** (файл відсутній) |
| Директиви для ботів | Не задані |
| Посилання на Sitemap у robots | Відсутнє |

Пошукові боти могли обходити весь опублікований сайт без явних обмежень; технічна документація в `/docs/` теоретично могла б індексуватись, якщо доступна за URL.

---

## 5.2. Повний вміст robots.txt (після оптимізації)

```
# robots.txt — SEO Demo Site (навчальний проєкт)
# https://mesiriak.github.io/seo-example/

User-agent: *
Disallow: /docs/
Disallow: /drafts/
Disallow: /private/
Allow: /

User-agent: Googlebot
Allow: /

Sitemap: https://mesiriak.github.io/seo-example/sitemap.xml
```

**Публічний URL файлу:** https://mesiriak.github.io/seo-example/robots.txt

---

## 5.3. Таблиця директив та обґрунтування

| Директива | Значення | Призначення | Обґрунтування для SEO Demo Site |
|-----------|----------|-------------|--------------------------------|
| `User-agent: *` | Всі боти | Група правил за замовчуванням | Стандартний блок для всіх краулерів |
| `Disallow: /docs/` | Заборона | Не індексувати звіти лабораторних | PDF/HTML-звіти в `docs/` — службові, не для SERP |
| `Disallow: /drafts/` | Заборона | Чернетки | Резерв для майбутніх чернеток (профілактика) |
| `Disallow: /private/` | Заборона | Приватний розділ | Резерв; на навчальному сайті розділу немає |
| `Allow: /` | Дозвіл | Явно дозволити корінь | Після Disallow уточнює, що публічні сторінки відкриті |
| `User-agent: Googlebot` | Google | Окремий блок для Google | Підтвердження доступу для основного пошуковика |
| `Allow: /` (Googlebot) | Дозвіл | Повний доступ Googlebot | Навчальний контент має індексуватись |
| `Sitemap:` | URL sitemap.xml | Вказівка на карту сайту | Прискорює знаходження 16 URL ботом |

**Не використовували:** `Disallow: /` (заблокував би весь сайт), `Crawl-delay` (ігнорується Googlebot).

---

## 5.4. Перевірка robots.txt

| Крок | Дія | Очікуваний результат |
|------|-----|----------------------|
| 1 | Відкрити https://mesiriak.github.io/seo-example/robots.txt у браузері | Відображається текст файлу, статус 200 |
| 2 | GSC → **Settings** → **robots.txt** → Open report | Файл зчитано, без критичних помилок |
| 3 | GSC → **URL Inspection** → `index.html` → Test live URL | Googlebot **allowed** |
| 4 | URL Inspection → `docs/lab03-section1.md` (якщо доступний) | Може бути **blocked** через Disallow /docs/ |

📸 **Скріншот 5.1** — браузер: вміст robots.txt  
📸 **Скріншот 5.2** — Google Search Console: звіт robots.txt (Retrieved / Valid)

---

## 5.5. Порівняння до / після

| Критерій | До | Після |
|----------|-----|-------|
| Наявність robots.txt | Ні | Так |
| Посилання на Sitemap | Ні | Так (`sitemap.xml`) |
| Захист службових `/docs/` | Ні | Так |
| Явний Allow для публічного контенту | — | Так |
| Готовність до GSC crawl | Часткова | Повна |

---

## 5.6. Висновок розділу 5

Створено **robots.txt** у корені сайту з коректними директивами для навчального проєкту: відкритий доступ до публічних HTML-сторінок, заборона індексації службового каталогу `/docs/`, оголошено **Sitemap**. Файл готовий до перевірки в Google Search Console після деплою на GitHub Pages.
