## 2.5. Конкурентна ситуація — висновки

### Де ви поступаєтесь
- **Referring domains:** 0 vs 2 700 (collaborator) та 100 000 (ahrefs) — критичний розрив.
- **Backlinks:** 0 vs мільйони у лідерів ніші.
- **Organic visibility:** 0 keywords/traffic vs сильні конкуренти.

### Де ви на рівні або сильні
- **Технічний SEO** (лаб. 01–03): метадані, schema, швидкість — конкурент **seomart** теж без посилань.
- **Чистий профіль:** немає токсичних links (на відміну від ризиків при агресивному лінкбілдингу).

### Стратегії конкурентів (що «позичити»)
1. **collaborator** — потрапляти в **огляди та рейтинги** (referr.com.ua, тематичні блоги).
2. **ahrefs** — потрапляти в **listicles** «best SEO tools / resources / guides for students».
3. Обидва — **guest posting** і **контекстні згадки**, не каталоги з exact match.

### Gap-можливості (головне для лабораторної)
- 5–7 доменів з link gap — реалістичні цілі для **перших 10 referring domains**.
- Фокус: **UA SEO-блоги**, **огляди інструментів**, **навчальні resource pages** (університети, курси digital).
