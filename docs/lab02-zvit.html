6. Висновки

У ході лабораторної роботи проведено комплексну on-page оптимізацію навчального сайту SEO Demo Site. Виявлено критичні проблеми початкового стану: односторінкова архітектура, короткі метадані без ключових слів, відсутність structured data та слабка внутрішня перелінковка з шаблонними anchor texts.

Після оптимізації створено 16 окремих сторінок з унікальними title (50–60 символів) та meta description (150–160 символів), імплементовано JSON-LD розмітку п'яти типів Schema.org та побудовано логічну hub-and-spoke модель internal linking.

Навчальні інсайти:

  1. Title tag — найважливіший елемент для релевантності та CTR; формула з брендом покращує впізнаваність.
  2. JSON-LD зручніший за microdata для підтримки та валідації.
  3. Internal linking має бути контекстуальним; anchor «читати більше» не передає семантику.

Рекомендації на майбутнє: додати Open Graph теги, canonical на всі сторінки, robots.txt з посиланням на sitemap, alt для всіх зображень, перевірити Core Web Vitals після деплою.

7. Відповіді на контрольні запитання

7.1. Чому title tag найважливіший on-page елемент?

Title — один із сильніших сигналів релевантності для пошукових систем; він відображається як заголовок сніпета в SERP і впливає на CTR. Прямо на ранжування впливає опосередковано через релевантність і поведінкові фактори (кліки). Оптимізований title з ключовим словом підвищує ймовірність кліку порівняно з загальним «Головна».

7.2. JSON-LD vs Microdata vs RDFa

JSON-LD — окремий блок у <script>, не змішується з HTML. Microdata — атрибути itemscope/itemprop у тегах. RDFa — атрибути typeof/property. Google рекомендує JSON-LD, бо його легше генерувати, підтримувати та валідувати без зміни видимої розмітки.

7.3. Featured snippets та structured data

Featured snippets — виділені блоки відповіді в TOP. Типи: paragraph, list, table, video, FAQ. FAQPage schema може допомогти з FAQ rich results; для звичайних snippets важливіше структурований контент (H2, списки, чіткі відповіді), ніж лише schema.

7.4. Link equity та internal linking

Link equity (PageRank) — «вага», що передається через посилання. Internal links розподіляють її з hub-сторінок на важливі cornerstone без зовнішніх посилань. Це покращує crawl depth і тематичні кластери.

7.5. Помилки Schema.org

Відносні URL, невідповідність JSON контенту сторінки, фейкові рейтинги, синтаксичні помилки JSON, відсутні обов'язкові поля, неправильний формат дати. Уникати: абсолютні URL, ISO-дати, валідація в Rich Results Test.

7.6. Anchor texts

Погано: «тут», «читати більше». Добре: «технічний SEO аудит», «on-page SEO оптимізація» — описують ціль і містять ключові слова природно.

7.7. Довжина title та description

Занадто довгі — обрізання «…» у SERP. Занадто короткі — втрата CTR і контексту. Оптимум: title 50–60, description 150–160 символів.
